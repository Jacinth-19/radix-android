Know the gate.
Understand the circuit.

Eight standard logic gates, twenty-three combinational circuits and eleven sequential models. This file is fully offline and phone-friendly. Open the app’s Logic tab to toggle inputs, follow live wires, inspect truth/state tables and simulate clock edges.

Combinational circuits depend only on present inputs. Sequential circuits also depend on stored state. Tables below are ideal Boolean models—not analog voltages, propagation delay, setup/hold violations or metastability. The app’s timing traces record actions, not real time.

The model describes logic only; it does not model current limiting, display wiring or physical polarity.
