RADIX 4 / OFFLINE STUDENT REFERENCE

Know the gate.
Understand the circuit.

Eight standard logic gates, twelve combinational circuits and eleven sequential models. This file is fully offline and phone-friendly. Open the app’s Logic tab to toggle inputs, follow live wires, inspect truth/state tables and simulate clock edges.

Combinational circuits depend only on present inputs. Sequential circuits also depend on stored state. Tables below are ideal Boolean models—not analog voltages, propagation delay, setup/hold violations or metastability. The app’s timing traces record actions, not real time.

SR latch · NOR

Cross-coupled gate implementation

10 set · 01 reset · 00 hold · 11 forbidden

Active-high, level-sensitive, cross-coupled NOR gates.

During S=R=1, both physical outputs are 0. Releasing to 00 leaves memory indeterminate until a valid set/reset.

“Release both to hold” models simultaneous release. Releasing one input first can instead enter a known set/reset state.
