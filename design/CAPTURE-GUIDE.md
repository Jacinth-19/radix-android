# Radix 6.0 — Guided native capture: shot list + recording instructions

You capture on **your own Android phone** (I can't see your screen). Follow the steps
in order; after each step, **send the files back here** and I'll check them and prep
the store-ready assets (resizing, feature graphic pairing, listing upload order).

## Step 0 — One-time prep (5 minutes)

1. Install the signed APK: `Radix-release.apk` (v6.0.0). If v5.0 is installed, it
   upgrades in place — that's fine, and it also lets you capture the What's New screen.
2. Charge to 60%+ and free ~500 MB (video takes space).
3. Turn on **Do Not Disturb** (Quick Settings) so no personal notifications appear.
4. Set brightness to ~75% and turn off auto-brightness (keeps shots consistent).
5. Optional but recommended: set display size to **Default** (Settings → Display),
   dark theme inside Radix Settings → Theme → Dark (our signature look).
6. Add the widget (for shot 12): long-press your home screen → **Widgets** → Radix
   → drag the daily-challenge widget somewhere clean.
7. Find your recorder: swipe down Quick Settings twice → **Screen record**.
   Set it to 1080p if it offers quality options, sound OFF (we add captions later).

**Reply to me when done:** "prep done + phone model + Android version".
I'll confirm, then you move to Step 1.

## Step 2 — The 40-second video (one continuous take)

1. Open Screen record → Start. Wait **2 silent seconds** on the home screen.
2. Tap converter → type `255` → show working (~6 s).
3. Open Practice → tap **Intermediate** → answer one question, show the +XP flash (~8 s).
4. Open **Circuit builder** → tap "Pulse A" → glitch/settle readout appears (~10 s).
5. Open **Float lab** → `0.1` decoded with the rounding note (~8 s).
6. Stop recording. **Do not narrate** — captions go on later.
7. Watch it once: if you fumbled a tap, re-record (take 2 is always better).

**Send the video back here.** I'll trim the ends, add captions, and export the
Play-Store cut (public/unlisted YouTube embeddable, ads off — only when you
approve an upload; nothing gets published without you).

## Troubleshooting

- **Recorder missing?** Use Play Store "Screen Recorder" by a reputable vendor,
  or capture on a second phone pointed at the first (last resort).
- **Keyboard covers content?** Tap back/done to dismiss, then screenshot.
- **Screenshot shows personal info?** Retake with DND on; crop status bar if needed.
- **APK won't install?** Allow "Install unknown apps" for your browser/Files app
  when prompted; the APK is signed with our RSA-4096 release key.
- **Widget not listed?** Open Radix once after installing, then check Widgets again
  (launchers refresh the list after first run).
